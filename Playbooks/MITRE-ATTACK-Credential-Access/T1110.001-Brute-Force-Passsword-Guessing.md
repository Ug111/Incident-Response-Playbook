## Technique Overview
Adversaries attempt to gain access by systemically guessing passwords,
often using dictionary or common-password lists against valid account

## Detection
- Multiple failed authentication attempts from single sources (threshold: 10+ in 5 min)
- SIEM correlation: repeated auth failures against same account
- Source: Splunk SPL search / Suricata SID 1000003

## Investigation Steps
1. Identify source IP and target account(s)
2. Check for successful login following failed attempts
3. Correlate against baseline authentication patterns
4. Determine if credential stuffing (multiple accounts) or targeted (single account)

## Containment
- Block source IP at firewall/WAF
- Force password reset if any success suspected
- Enable/tighten account lockout policy
